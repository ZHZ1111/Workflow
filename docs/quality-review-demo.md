# 45 秒三 Agent 演示讲稿

材料：[证据回放](../evaluation/quality-review-demo.html)、[完整轨迹](../evaluation/quality-review-s9-demo.json)。所有模型响应为固定夹具，执行为真实 pytest/coverage，外部请求为零。

| 时间 | 画面 | 讲解 |
|---|---|---|
| 0–7.5 秒 | 生成 Agent，首轮两个测试 | “先验证 50 和 150，分别覆盖不打折和打折。” |
| 7.5–15 秒 | 执行 Agent，2 passed、100% / 100% | “真实测试已全部通过，覆盖率也已满，但还需要质量审查。” |
| 15–22.5 秒 | 审查 Agent，规格原文 | “规格说大于等于 100 打九折，恰好 100 的门槛尚未独立验证。” |
| 22.5–30 秒 | 生成 Agent，消费消息与 diff | “第一轮反馈由第二轮消费，保留原测试，新增 100 应返回 90。” |
| 30–37.5 秒 | 执行 Agent，3 passed | “新候选重新执行，三个测试都通过，覆盖率仍是满的。” |
| 37.5–45 秒 | 审查批准、选中第 2 轮和 SHA-256 | “审查批准本轮候选，最终文件来自第 2 轮，所有证据可以追溯。” |

开场或结尾说明：“这是固定响应驱动的机制演示，真实模型验收单独记录；不把离线反馈冒充真实模型判断。”

如需现场执行而非回放，先运行 `python scripts/prepare_quality_demo.py`（使用 README 的虚拟环境解释器）。本次实测完整离线任务耗时 3.91 秒；重跑耗时随系统负载变化，不保证精确时长。真实模式的行为规格不包含“首轮故意遗漏”的演示要求。
