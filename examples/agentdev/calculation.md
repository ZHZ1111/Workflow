# 正常计算：calculate_total

## 行为约定

- `unit_price` 为非负整数单价，`quantity` 为非负整数数量，均不包含 `bool`。
- 返回整数 `unit_price * quantity`，不收取额外费用，也不限制结果上限。
- 单价或数量为 0 时返回 0。
- 输入域是前置条件；负数、浮点数、字符串、布尔值等域外输入的行为未定义，不要求抛出某种异常。
- 函数不修改输入，不读写文件，不访问网络。

## 可核验场景

| unit_price | quantity | 预期结果 |
|---:|---:|---:|
| 12 | 3 | 36 |
| 0 | 5 | 0 |
| 12 | 0 | 0 |
| 0 | 0 | 0 |
| 1 | 1 | 1 |
| 1000000 | 1000000 | 1000000000000 |

上述值用于建立有效断言；无条件分支时分支覆盖率应显示为不适用。
