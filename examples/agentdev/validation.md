# 多分支校验：classify_score

## 行为约定

- 输入 `score` 必须为整数且不属于 `bool`；接受整数子类，布尔值除外。
- 先检查类型：浮点数、字符串、`None`、布尔值等抛出 `TypeError`，不进行类型转换。
- 类型合法后检查范围：小于 0 或大于 100 抛出 `ValueError`。
- 范围合法时：0–59 返回字符串 `fail`；60–89 返回 `pass`；90–100 返回 `excellent`。
- 不约束异常消息文本，只约束异常类型；函数无外部副作用。

## 可核验场景

| 输入 | 预期 |
|---|---|
| `0`, `59` | `"fail"` |
| `60`, `89` | `"pass"` |
| `90`, `100` | `"excellent"` |
| `-1`, `101` | 抛出 `ValueError` |
| `60.0`, `"60"`, `None` | 抛出 `TypeError` |
| `True`, `False` | 抛出 `TypeError` |

测试需要覆盖类别交界和两侧越界；仅验证一个正常成绩不能说明分支已充分覆盖。
