# 明确规格下的缺陷：calculate_discount

## 行为约定

- 输入 `amount` 是非负整数金额，单位为元；接受整数子类，但不接受 `bool`。
- 布尔值及非整数抛出 `TypeError`；负整数抛出 `ValueError`。先检查类型，再检查范围，不做隐式转换。
- 金额 **大于等于 100** 时打九折，返回 `amount * 9 // 10`，即向下取整后的整数金额。
- 金额小于 100 时返回原金额；0 返回 0。
- 不约束异常消息文本；函数无外部副作用。

## 可核验场景

| 输入 | 预期 |
|---|---|
| `0` | `0` |
| `99` | `99` |
| `100` | **`90`** |
| `101` | `90` |
| `110` | `99` |
| `-1` | 抛出 `ValueError` |
| `100.0`, `"100"`, `None`, `True`, `False` | 抛出 `TypeError` |

## 样例用途

对应源码有意使用 `amount > 100`，因此在 `100` 时实际返回 `100`，违反满 100 打折的约定。保留该缺陷用于后续演示：有效的规格断言失败时，Agent 应输出 `needs_review` 和疑似缺陷证据，保留预期值 `90`，不修改源文件或把预期改成 `100`。

这是预先设定的样例缺陷说明，不能作为真实 Agent 已完成检出的证据；后续仍需实际生成并执行测试。
