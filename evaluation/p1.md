## 复现

```powershell
.\.venv\Scripts\python.exe -m pip install --no-index --no-build-isolation --no-deps -e .
.\.venv\Scripts\python.exe scripts/p1_baseline.py
.\.venv\Scripts\python.exe -m test_workflow demo --source examples/calculation.py --spec examples/calculation.md
```

前提是按 README 安装锁定依赖与 vendor。运行脚本会创建新的任务并更新精简证据与示例。

开发时发现 pytest 默认导入模式会让 `tests/test_workflow.py` 遮蔽同名包，已将测试文件改为 `test_runner.py`。受限执行环境还阻止 Python `Path.resolve(strict=True)` 解析仓库输入文件；本机离线验证在自动审核允许的执行权限下完成，保留了真实路径归属检查。安装时把临时目录设到仓库 `outputs/p1/build-tmp`，无需下载新依赖。

P0 的 vendor 全量测试结果仍单独保存，本阶段没有修改 vendor 业务源码或旧 hw1 工程。P2/P3 的真实单步生成/执行、P4 的反馈与完整结果路由、P5 的真实模型验收、P7 的干净安装尚未完成；本记录仅证明 P1 契约与假节点链路。
