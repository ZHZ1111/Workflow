## 五个确定案例

| 场景 | 结论 |
|---|---|
| calculation 合法首轮 | 一个候选落盘，计划/客户端结果保留，发出 candidate_ready |

| 弱化 test_score_pass 的等值断言 | preserve_tests 拒绝，旧测试不变，无执行交接 |

三个修订场景各有一次由验收脚本在生成节点外执行的真实 pytest/coverage，合计 3 次。这证明历史保护依据真实通过测试，未冒充 P3 执行 Agent 已实现。首轮成功不意味着完整任务 completed；验收状态保持 running，task_status 为 null。

每组完整证据路径从 p2_results.json 的 samples.<name>.run_dir 查询。外层 node_results 保存 Context/Result，handoffs 保存统一候选，内层保存原 vendor 文件。十个可校验的契约 JSON 和当前验证 Schema 已保存到 examples/contracts/p2/。
